# Adnan Shanavas – Portfolio (Next.js + NestJS)
Terminal 1: `cd backend && npm i && npm run start:dev`   (API on :4000)
Terminal 2: `cd frontend && npm i && npm run dev`        (site on :3000)
Set `API_URL` in frontend/.env.local if the API runs elsewhere (default http://localhost:4000).
All content lives in backend/src/portfolio.data.ts (taken from the resume).
